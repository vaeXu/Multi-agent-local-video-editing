# 《代签》第一集 · 签字页

- **剧名**：代签
- **集数**：EP01（第一集《签字页》）
- **时长**：73 秒（12 镜，单镜 5~7 秒）
- **题材**：都市悬疑 / 职场反转 · 真人漫剧（竖屏 9:16）
- **一句话梗概**：合规专员当众指控项目负责人代签文件，两人顺着纸上的压痕查出第三方，而他亮出的工牌让这场审问整个翻了过来。
- **前 3 秒钩子**：会议室里，苏晴把一张签字页「啪」地拍在长桌上，指尖压住签名，当众直指对面的林昭——「不是我签的，是你代签的。」

---

## 场景

现代写字楼 17 层，玻璃隔断会议室。深胡桃木长桌、白墙、投影幕、右侧整面落地窗（阴天漫射光）。冷白 LED 顶光为主，窗外天光为辅，整体低饱和青灰冷调，木质桌面带一点暖色反光。时间：白天，会议中途，室内只有两人。

## 人物

- **林昭**（男，Eddy）：表面是被人指认的项目负责人，实为总部派驻的合规稽核。黑色短碎发、银色细框眼镜、深灰三件套西装。刚性特征：左眉尾一道浅疤、左手腕方形钢带机械腕表、银色回形针领针。全程语速平稳，不争辩，只找证据。
- **苏晴**（女，Sandy）：合规专员，干练利落。齐肩栗棕色内扣直发、米白收腰西装。刚性特征：右耳单只小珍珠耳钉、左手食指素圈银戒、左领圆形金属工牌。开场咄咄逼人，中途开始动摇。

## 全剧画风

写实国漫 · 都市冷调电影感。全剧 12 镜统一：真人实拍参考帧转绘，冷白顶光 + 落地窗侧光，低饱和青灰与暖木色对比，浅景深，干净描边与轻网点，同一套色彩分级；角色五官、发型、服装、锚点特征、光线色调跨镜严格一致，无画风跳变、无撞脸、无换脸。

## 分镜剧本

### S01 · 6s · 过肩近景 / 缓推
**画面**：从苏晴左肩后约一米、略俯 10 度拍摄。冷白顶光 + 右侧落地窗阴天侧光，浅景深。一只涂裸色指甲油的右手把 A4 签字页平拍在深胡桃木长桌，食指压住签名栏，纸角翘起。背景虚化的白墙、投影幕、半杯黑咖啡，桌面映出顶光光带。苏晴占右三分之一，左侧留白给字幕，视线射向画外的林昭。
**动作 / 情绪**：肩线绷直、下巴微抬，指尖用力压纸不松。压低声音、克制。
**台词（苏晴）**：「不是我签的，是你代签的。」
**音效**：拍桌声、纸响　**字幕**：不是我签的，是你代签的。

### S02 · 6s · 特写 / 缓推
**画面**：正面平机位缓推至眼部。冷白顶光在镜片留一道细高光，背景虚成青灰。林昭银色细框眼镜后的眼睛抬起直视镜头，左眉尾浅疤随抬眉轻牵；左手抬起时袖口露出方形钢带机械腕表；深灰立领与银色回形针领针入画下缘。面部居上三分之二。
**动作 / 情绪**：下颌收紧、嘴唇抿成一条线，不躲视线。平静。
**台词（林昭）**：「会议室有监控，调出来。」
**音效**：椅子轻响　**字幕**：会议室有监控，调出来。

### S03 · 6s · 插入大特写 / 俯拍固定
**画面**：俯拍 45 度，平板屏幕自发光作主光源，冷蓝光打在指尖，四周压暗。戴素圈银戒的左手把平板横转，屏幕停在一张监控截图：空会议室、右上角时间戳 21:07，拇指指甲轻点时间戳；屏幕边缘映出右耳单只珍珠耳钉的一点反光。屏幕占画面中部。
**动作 / 情绪**：手腕稳，拇指定点一戳。逼近、冷静。
**台词（苏晴）**：「昨晚九点，只有你进过。」
**音效**：手机震动　**字幕**：昨晚九点，只有你进过。

### S04 · 7s · 近景 / 缓推
**画面**：桌侧 35 度机位缓推。平板冷光从下方补亮下颌，顶光退成轮廓光。林昭上半身前倾凑近屏幕，银框眼镜下滑半寸，瞳孔骤然收窄、视线定在一点，右手食指指节在木桌面连叩两下；左眉浅疤与钢带腕表随动作入画。背景虚化的百叶窗与投影幕。人物偏左，右下留字幕。
**动作 / 情绪**：前倾、叩桌两下，节奏放慢。笃定。
**台词（林昭）**：「九点零七，灯是灭的。」
**音效**：指节叩桌声　**字幕**：九点零七，灯是灭的。

### S05 · 5s · 物件大特写 / 垂直俯拍固定微距
**画面**：一束侧逆光斜扫纸面显出凹凸，冷白为主、暖木反光为辅。林昭指腹从左向右缓慢抚过签字页的签名笔画，斜光下浮出一层与签名错位的浅压痕；深灰袖口与钢带腕表压在画面左缘；可见纸纤维、墨色浓淡、杯底一圈淡咖啡环印。签字页占满画幅，压痕居中。
**动作 / 情绪**：指腹平移、在压痕处停半拍。低声。
**台词（林昭）**：「纸下面，还有一层压痕。」
**音效**：纸声　**字幕**：纸下面，还有一层压痕。

### S06 · 6s · 特写 / 极缓摇
**画面**：正面略侧 15 度，落地窗侧光从右打亮半边脸，左半脸落柔和阴影。苏晴眼睫连眨两下、视线从屏幕移开又落回，嘴唇微张即抿；右耳单只珍珠耳钉随转头晃出一点高光，别着圆形工牌的米白西装领口入画下缘，持平板的手缓缓收回胸前；栗棕内扣发尾擦过肩。面部居上。
**动作 / 情绪**：收手、眨眼、视线下移。迟疑。
**台词（苏晴）**：「压痕……什么意思？」
**音效**：空调声　**字幕**：压痕……什么意思？

### S07 · 6s · 中近景 / 低机位仰拍固定
**画面**：人物背后落地窗强逆光勾轮廓，室内补一面柔光反光板提亮面部，暖窗光与青灰室内冷暖对比。林昭双手捏住签字页两角举向窗前，纸张被光透出底层被描过的重叠笔画；银框眼镜反着窗光，左眉浅疤与立领领针清晰，指节因用力微微发白。背景过曝窗格与虚化城市天际线。人物居中偏下，透光纸面为焦点。
**动作 / 情绪**：举纸齐眉、双手不动，让光穿过纸。平稳。
**台词（林昭）**：「有人照着，描过一遍。」
**音效**：窗帘轻响　**字幕**：有人照着，描过一遍。

### S08 · 6s · 双人中景 / 正面固定
**画面**：两人隔长桌一左一右对称入画，背后落地窗逆光镀亮轮廓，室内冷白补光。左侧林昭举纸的手未放下、银框眼镜与钢带腕表朝右；右侧苏晴上半身前倾凑近纸面、珍珠耳钉与米白工牌朝左；两人视线在画面中线的透光纸页交汇。桌面一杯黑咖啡与平板居中。严格左右对称，上方留窗光、下方留字幕。
**动作 / 情绪**：同时定住，只有苏晴肩膀再前倾一寸。短促追问。
**台词（苏晴）**：「谁？」
**音效**：心跳声　**字幕**：谁？

### S09 · 7s · 物件大特写 / 俯拍缓推
**画面**：俯拍 40 度，手机屏幕冷光加顶部射灯，桌面压成暗青灰。林昭拇指把签字页翻到背面，纸角一枚浅红色圆形审批章与一串细小章号入画；另一只手举手机对准章号扫码，钢带腕表与深灰袖口压在画面右缘，扫码框亮起一道绿光。可见纸张翻折痕、油墨边缘、镜头反光。章号居上三分之一。
**动作 / 情绪**：翻纸、抬手机、屏住不动。压低。
**台词（林昭）**：「章号，不在这层楼。」
**音效**：扫码提示音　**字幕**：章号，不在这层楼。

### S10 · 6s · 近景 / 缓推
**画面**：冷白顶光转柔，苏晴半边脸被落地窗侧光勾亮。她握文件的左手骤然收拢、食指素圈银戒磕在桌沿，指节泛白；喉结轻动一次、视线快速下移再抬回；右耳珍珠耳钉静止，栗棕内扣发尾随低头滑到颊侧，米白西装左领圆形工牌轻晃。背景虚化白墙与椅背。人物偏右，左下留字幕。
**动作 / 情绪**：攥紧文件、喉头一动、视线一沉。气声、发紧。
**台词（苏晴）**：「这文件……是塞给我的。」
**音效**：呼吸声　**字幕**：这文件……是塞给我的。

### S11 · 6s · 手部与证件特写 / 平机位急推
**画面**：冷白顶光在塑料卡面打出一道竖向高光，背景会议室虚成青灰。林昭从深灰西装内袋抽出一枚工牌，两指翻转到正面，卡面印总部合规稽核字样与一枚钢印；方形钢带腕表随翻腕露出，银色回形针领针在画面上缘入镜，拇指压住卡角不抖。可见卡面磨痕、挂绳织物、钢印凹凸。工牌居中心偏上。
**动作 / 情绪**：抽卡、翻面、停稳，手腕不晃。坦然。
**台词（林昭）**：「我不是来被审的。」
**音效**：皮夹开合声　**字幕**：我不是来被审的。

### S12 · 6s · 中景转半身 / 右后侧缓拉（留悬念）
**画面**：冷白顶光渐暗、只剩落地窗余光，走廊门缝透进一道细长暖光横过地面，青灰冷调。林昭右手举手机看屏，屏幕亮起一行「第 2 份已签收」与空白签收人栏；左眉浅疤与银框眼镜反射屏光，他视线忽然从屏幕抬向画右门缝——那里有一截一闪而过的人影与半只皮鞋，钢带腕表垂在身侧。背景虚化会议椅与半开玻璃门。人物居左，右侧门缝光带留白，下方留字幕。
**动作 / 情绪**：抬眼、视线钉在门缝，身体不转。留白、压低。
**台词（林昭）**：「这页，只是第一份。」
**音效**：手机震动、门响　**字幕**：这页，只是第一份。
